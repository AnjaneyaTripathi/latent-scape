# Summary provenance

Paper summaries are one-time, agent-authored Astra outputs requested for this
project. They are generated offline and stored with each paper's
`summary.source`, `summary.model`, and source-abstract hash. The browser only
reads the resulting static JSON. It renders the unchanged source abstract
first, followed by a TLDR and three to five explanatory paragraphs. The full
export reports current narratives, legacy summaries, pending eligible papers,
and unavailable papers separately; it does not claim all papers are curated.

Every rendered summary and TLDR must display **AI-generated summary** beside the original-paper link. The summary is a navigation aid, not a source: readers should follow the outbound proceedings, OpenReview, or arXiv link for the original work.

Runner working directories, logs, archives, and schemas are transient and
ignored by Git; final summary shards and clean provenance reports are retained.
`config.toml` stays untracked; `config.example.toml` only documents optional
provider settings for a future locally authorized rerun.

`data/generated/summary-provenance-report.json` is regenerated by
`scripts/write-artifact-report.py` after every static build. It separates
authoring-run volume from the summaries actually rendered in that artifact:
stale source-hash outputs are never counted as current. CLI runs record actual
reported tokens when available; interactive Astra review batches and local
Codex account charges are reported as unknown rather than estimated as facts.
